# community-site 社区站

组内共建的二次元风格社区站。服务器与域名由组长提供，全组共同构建、共同维护。

## 四大板块

| 板块 | 内容 | 负责人 |
|------|------|--------|
| 🏠 门户（首页） | 群介绍、公告、关于我们、加入群 | 组长 |
| 🧰 功能区 | 实用工具、服务入口、资源导航 | 凉心白日 |
| 📚 学习区 | 技术笔记、教程、踩坑记录 | 池棠 |
| 👤 个人区 | 成员页：自我介绍、作品、个性化 | 全体 |

3. 改完 git add → commit → push，main 永远可跑
