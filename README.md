# community-site 社区站

组内共建的二次元风格社区站。服务器与域名由组长提供，全组共同构建、共同维护。

## 五个职能板块

| 板块 | 干什么 | 负责人建议 |
|------|--------|-----------|
| 维护 | 服务器、部署、监控、安全 | 组长 |
| 前端 | 网站壳、页面、UI/交互 | 池棠 + 凉心白日 |
| 后端 | Python API、动态功能、数据 | 池棠 + 凉心白日 |
| 插件 | 小工具、第三方集成、资源导航 | 小狄，组长等 |
| 设计 | 二次元风格、素材、品牌 | 池棠 |
