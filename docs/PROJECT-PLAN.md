# community-site 社区站 —— 项目草案 v0.1

> 日期：2026-08-21 ｜ 状态：草案，待全组讨论后定稿

## 一、项目定位

**一句话：组内共建的二次元风格社区站——不只是群介绍，是挂服务、资源、工具，学习交流和个人展示的地方。**

- 服务器 + 域名由组长提供（塔 + 子域名）
- 全组共同构建、共同维护
- 框架先行，个性化各玩各的

## 二、四个大板块

### 板块一：门户（首页）—— 群的窗口
- 群介绍：一段话 + 组图
- 公告栏：最新动态、招募信息
- 关于我们
- 加入群窗口（QQ 群链接 / 二维码）
- 页脚：站点信息

**负责人：组长**

### 板块二：功能区（工具与服务）—— 留人的地方
- 实用在线工具（组员开发的小工具：查 IP、二维码生成、文本处理等）
- 服务入口（组里挂的服务：机器人、API、内部系统）
- 资源导航（学习资料、教程、好用的链接）

**负责人：凉心白日**

### 板块三：学习区（文章与笔记）—— 学习交流
- 技术笔记、教程、踩坑记录
- 按作者归档，每篇带：标题、作者、日期、标签
- 写作格式：Markdown

**负责人：池棠**

### 板块四：个人区（成员页）—— 个性化
- 每人一个页面：自我介绍、技能、作品、社交链接
- 框架提供模板，个人自由发挥（套上壳即可）
- 谁都能有自己的小窝

**负责人：全体成员**

## 三、技术栈（统一，不搞多语言混搭）

| 层 | 技术 | 理由 |
|----|------|------|
| 前端 | HTML/CSS/JS 静态壳 | 零依赖、零构建、谁都看得懂、个性化简单 |
| 后端 | Python（二期，FastAPI/Flask） | 团队交集最大的语言 |
| 部署 | nginx + 组长服务器 | 现成的 |

**原则：语言统一。语言越多越不稳定（组长拍板）。**

## 四、仓库结构（规划）

```
community-site/
├── README.md        # 仓库门面：项目简介 + 板块速览
├── docs/            # 文档：本草案、协作规范
└── site/            # 网站代码（一期）
    ├── index.html   # 首页（板块一）
    ├── assets/      # 壳：主题 CSS/JS
    ├── services/    # 功能区（板块二）
    ├── blog/        # 学习区（板块三）
    └── members/     # 个人区（板块四）
```

## 五、路线图

- **一期（现在）**：静态框架 + 四个板块骨架上线，预览链接给全组
- **二期**：Python 后端（等凉心白日的草案）→ 动态功能（留言、计数器）
- **三期**：功能区充实、个人页开放、各板块按需个性化

## 六、协作规范

1. main 永远可跑
2. 各人只动自己的板块目录
3. 改动 = 加文件 / 改自己的文件；大改动先讨论再动手
4. README 和 docs/ 是交接文档，新成员先读这里
