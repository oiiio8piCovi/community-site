# community-site 社区站 —— 项目草案 v0.1

> 日期：2026-08-21 ｜ 状态：草案，待全组讨论后定稿

## 一、项目定位

**组内共建的二次元风格社区站——不只是群介绍，是挂服务、资源、工具，学习交流和个人展示的地方。**

- 服务器 + 域名由组长提供
- 全组共同构建、共同维护
- 框架先行，个性化

## 二、五个职能板块

> 按**职能**分工：每人一个明确的技术角色，各练各的，又互相配合。

### 板块一：维护（运维）
**干什么**：服务器与域名、部署发布、监控备份、安全
- 服务器 + 域名
- 部署：nginx + git 发布流程（改完推送 → 自动上线）
- 监控：网站挂了能第一时间知道
- 安全：防火墙、权限、密钥管理

**一期要交**：网站上线 + 自动发布流程

**主要负责人**：组长（网络 + Linux）

### 板块二：前端
**干什么**：网站壳 + 页面 + UI/交互
- 首页、导航、五个板块的页面骨架
- 响应式（手机上也要能看）
- 动画、交互细节

**一期要交**：能看的网站壳（组长先搭，后续交接）

**主要负责人**：认领（壳由组长先搭）

### 板块三：后端
**干什么**：Python API + 动态功能 + 数据
- API 服务（FastAPI / Flask）
- 动态功能：留言板、访问计数、搜索
- 数据存储

**一期要交**：后端草案（凉心白日）

**负责人建议**：池棠+ 凉心白日（草案）

### 板块四：插件
**干什么**：小工具 + 第三方集成 + 资源挂载
- 在线小工具（各自开发：查 IP、二维码、文本工具）
- 第三方集成（机器人、外部 API 接入）
- 资源导航（教程、工具、好用的链接）

**一期要交**：第一个小工具上线

**负责人建议**：小狄，组长，及其他成员

### 板块五：设计
**干什么**：视觉风格 + 素材 + 品牌
- 二次元风格定调（主题、配色、字体）
- 图标、图片、素材
- 品牌：名字、Slogan、Logo

**一期要交**：站点主题（配色 + 首屏视觉）

**负责人建议**：认领（池棠）

## 三、技术栈（统一，不搞多语言混搭）
| 前端 | HTML/CSS/JS 静态壳 | 零依赖、零构建、谁都看得懂、个性化简单 |
| 后端 | Python（二期，FastAPI/Flask） | 团队交集最大的语言 |
| 部署 | nginx + 组长服务器 | 现成的 |

**语言越多越不稳定**

## 四、仓库结构（规划）

```
community-site/
├── README.md        # 仓库门面：项目简介 + 板块速览
├── docs/            # 文档：本草案、协作规范
└── site/            # 网站代码（一期）
    ├── index.html   # 首页（前端负责）
    ├── assets/      # 壳：主题 CSS/JS（设计 + 前端负责）
    ├── services/    # 插件板块：小工具、资源导航
    ├── blog/        # 内容区：文章、笔记
    └── api/         # 后端：Python 服务（二期）
```

## 五、路线图

- **一期（现在）**：静态框架 + 五个职能板块骨架上线，预览链接给全组
- **二期**：Python 后端（等凉心白日的草案）→ 动态功能（留言、计数器）
- **三期**：插件工具充实、各板块按需发挥

## 六、协作规范

1. 各人只动自己的板块目录
2. 改动 = 加文件 / 改自己的文件；大改动先讨论再动手
3. README 和 docs/ 是交接文档，新成员先读这里
