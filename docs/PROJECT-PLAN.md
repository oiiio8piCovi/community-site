# AC社区 项目章程 v1.0

> 状态：定稿（2026-08-23）｜ 全称：Animation & Computer Science Community

## 一、项目概述：为什么做

一个群聊承载不了作品。我们想把自己学的东西、做的东西、发现的好东西，放在一个**属于全组的地方**——它能挂服务、挂资源、挂工具，能写文章、能交流，每个人都能在这里留名。

**一句话**：组内共建的二次元风格社区站，学习交流 + 作品落地的据点。

## 二、目标与非目标

**目标**
1. 全组共同构建、共同维护，每个人都有自己负责的板块
2. 站长在塔（服务器），域名来自 anonnet.top
3. 一期上线"能看的壳"，二期上动态功能，三期充实内容

**非目标（一期不做）**
- 不做账号注册登录系统
- 不做评论/私信等社交功能
- 不做多语言混搭的技术栈（统一 HTML/CSS/JS + Python）

## 三、五个职能板块

| 板块 | 干什么 | 一期要交 | 负责人 |
|------|--------|---------|--------|
| 维护 | 服务器与域名、部署发布、监控备份、安全 | 网站上线 + 自动发布流程 | 组长 |
| 前端 | 网站壳、页面、UI/交互、响应式 | 能看的网站壳 | 池棠 + 凉心白日 |
| 后端 | Python API、动态功能、数据存储 | 后端草案（已完成） | 池棠 + 凉心白日 |
| 插件 | 小工具、第三方集成、资源导航 | 第一个小工具上线 | 小狄，组长及其他成员 |
| 设计 | 视觉风格、素材、品牌（名字/Logo/口号） | 站点主题（配色 + 首屏视觉） | 池棠 |

## 四、内容板块（面向访客）

| 板块 | 放什么 | 对应职能产物 |
|------|--------|-------------|
| 首页 | 名字、口号、最新动态 | — |
| 工具 | 在线小工具（查 IP、二维码、文本工具） | 插件板块 |
| 资源 | 资源导航 + 友链 | 插件板块 |
| 文章 | 学习笔记、教程、更新记录 | 全员可写 |
| 留言 | 交流板 | 后端板块（草案已含） |

## 五、技术栈决策

| 层 | 选型 | 为什么 |
|----|------|--------|
| 前端 | HTML/CSS/JS 静态壳 | 零依赖、零构建、人人都能看懂和修改，个性化简单 |
| 后端 | Python（FastAPI） | 团队交集最大的语言；草案已出 |
| 部署 | nginx + 组长服务器 | 现成的，不需要额外成本 |
| 数据（二期后） | mock_db 起步 → SQLite/MySQL | 草案阶段用内存数据调试 |

**原则**：语言越多越不稳定。谁想加新技术栈，先在群里讲清楚理由。
