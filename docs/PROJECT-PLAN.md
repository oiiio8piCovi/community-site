# AC社区 项目章程

**全称：Animation & Computer Science Community**

章程记录组织目标、分工与规矩。现状与使用见 README。

## 目标

组内共建的二次元风格社区站，承载全组的学习成果、作品与资源，用于学习交流和个人展示。

## 进度

一期进行中：网站壳、演示站、文档已完成；二期动态功能草案就绪。

## 板块分工

| 板块 | 干什么 | 负责人 |
|------|--------|--------|
| 维护 | 部署、域名、监控、安全 | 组长 |
| 前端 | 页面、UI/交互 | 池棠 |
| 后端 | Python API、数据 | 凉心白日 |
| 插件 | 小工具、资源导航 | 小狄 + 全员 |
| 设计 | 视觉风格、品牌 | 全组讨论，前端落地 |

## 协作流程

讨论需求 → 定需求 → 任务单（GitHub Issue）→ 派发 → 改代码 → PR → 合并

- 任务单带验收标准
- 各人只动自己的板块目录
- 大改动先讨论再动手

## 技术栈决策理由

| 决策 | 理由 |
|------|------|
| 前端 HTML/CSS/JS | 零依赖、零构建，人人都能看懂和修改 |
| 后端 Python FastAPI | 团队交集最大的语言，草案已出 |
| 数据 mock_db → SQLite | 草案用内存调试，上线换文件数据库 |

## 原则

1. 加新技术栈，先在群里讲理由
2. 大改动先讨论再动手
