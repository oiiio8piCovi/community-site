## Contributing to This Project

We warmly welcome contributions! To get started, please review the following guides located in the `docs/` directory:

* ARCHITECTURE.md – Understand the project structure, design decisions, and technical stack.
* COLLABORATION.md – Learn about our workflow, communication channels, and code review process.
* PROJECT-PLAN.md – See the current milestones, feature roadmap, and prioritised tasks.
* ROADMAP.md – Get a high-level view of the project's future direction and release timeline.

## Quick Start

1. Fork the repository and create your branch from main.
2. Read the architecture and collaboration docs before writing any code.
3. Submit a pull request with a clear description of your changes, referencing any related issues.

## Questions?

If anything is unclear, please open a Discussion or ping a maintainer. We are happy to help!

Thank you for contributing!
